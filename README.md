## Scope and limitations

The main results concern certificate representation and conversion. The geometric implementation does not realise the deterministic near-linear theoretical construction. The retained V3 comparison favours event refinement on the tested lower family, and the separate P6 route failed its practical continuation criteria. The empirical certificates concern encoded loss tables, not population generalisation or radar calibration performance. Grouping 23 raw fields retains overlap after projection to the 19 fitting predictors.
