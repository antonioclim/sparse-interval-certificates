## Changes and scope

The package contains exact certificate producers and separate checkers, sparse continuous conversion, regularity diagnostics and retained reproducibility materials. This version adds Supplementary Software 4: validated-envelope checking, prescribed-margin synthesis, implicit DAG path checking, constant-mixture comparisons and the bounded RouterBench, ASlib and Padua studies.

RouterBench source files, aggregate numerical inputs and dependent numerical proof files are not redistributed. Software 4 identifies the official source revision and checksums and supplies reconstruction code. In the recorded internal validation, all 66 RouterBench fixtures and encoded instances were reproduced byte-for-byte; full exact replay checked 255 records and 94 table mappings in normal and optimised Python. A separate packaged-subset mode checks only the evidence included without the RouterBench source. These checks are not external replication or formal verification.

The retained studies include adverse results. None of the 94 exploratory cases supplied a new example combining interval-wide Pareto efficiency with interval-wide unsupportedness. No realised deployment savings, population guarantee or general performance superiority is claimed. The preserved core runtime baseline is 0.1.0-dev.10; distribution version 1.1.0 does not relabel historical generating sources.
