# Sparse interval certificates technical documentation and scientific companion

Version **1.2.0** · Antonio Clim · Version DOI: https://doi.org/10.5281/zenodo.23921914

This distribution adds the current scientific companion and complete technical
documentation to the preserved research-software materials. The scientific
companion contains the JGO manuscript, separate article Appendices A–C, three
thematic supplements and guarded native-document reconstruction sources. Its
own `docs/` tree includes the complete canonical Markdown, offline HTML,
locally typeset mathematical SVG/MathML and exact tabular records.

Read the [technical documentation](docs/README.md), download
the [offline documentation](https://github.com/antonioclim/sparse-interval-certificates/releases/download/v1.2.0/RADAR_Technical_Documentation_1.2.0.zip)
or obtain the [scientific companion](https://github.com/antonioclim/sparse-interval-certificates/releases/download/v1.2.0/RADAR_JGO_Scientific_Companion_1.2.0.zip).
The claim-and-evidence map locates the indispensable proofs, measurement
contracts and complete computational records. Thematic supplements retain
scientific qualifications and adverse outcomes.

The seven original scientific ZIP files retain their exact version 1.1.0
bytes, source versions and recorded evidence. This distribution label does
not change the historical runtime baseline. The version-specific compatibility
helper is also unchanged. New document and documentation sources are an
explicit later stage; old native and scientific guards remain intact.

The 17 named files in RELEASE_ASSETS_1.2.0.json/SHA256SUMS_1.2.0.txt constitute
the matching GitHub and Zenodo distribution. GitHub's two automatic source
archives contain documentation and distribution metadata; the named ZIPs
remain the scientific and document-reconstruction payloads.

Original code is BSD-3-Clause. Original non-code contributions are CC BY 4.0,
subject to retained component-specific rights and exclusions. Restricted
RouterBench numerical sources, aggregates and dependent proof payloads remain
excluded. See RIGHTS_STATUS.md and notices within each component.

The asset JSON hashes 15 payload files; SHA256SUMS hashes the other 16 files,
including that JSON. Each excludes itself. These checksums describe the named
release/deposit files, rather than renamed metadata indexes in the repository.

The version DOI was reserved in the author-supplied Zenodo draft at build time.
These files were frozen for author publication; the service publication state
is verified separately. This build performs no GitHub Actions, publication or
journal submission. Native Word/Windows testing and external human replication
retain their recorded limits.
