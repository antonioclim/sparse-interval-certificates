# Figure reconstruction and provenance

<a id="current-eight-figures"></a>

## Current editable figure set

The current companion supplies six article figures and two supplementary figures. The manuscript retains its figure captions and their scientific scope. Native ODG/FODG, live-text SVG, vector PDF, PNG, exact model inputs and object maps accompany the figure workflow. Journal TIFF aliases are production exports, rather than additional scientific figures.

The current figure source entry point is `run_figures_a2.py` inside `Figure_Sources`. Its generation and comparison commands are documented in the kit's reproduction README and dependency matrix. The current document route may invoke all eight figure checks through its documented figure option. Figure export does not regenerate manuscript PDFs.

<a id="source-and-interpretation"></a>

## Source interpretation

Analytic constructions are distinguished from retained measurements and computational observations. Rational model inputs are checked before conversion to floating point for rendering where that conversion is used. The recorded timing figures summarise the specified retained campaigns; new drawing code does not create new timing observations.

The four missing historical plotters remain unrecovered. The supplied current analytic generators are new implementations from retained attributable inputs. Historical sources and figures remain part of the source chain, without presenting their existence as recovery of those missing implementations.

<a id="maps-and-production"></a>

## Maps and production exports

The current kit's figure map binds the intended journal upload names, native sources, vector alternatives, preview images, model data and verification records. Use that map for local path resolution. Historical A4/A5 maps retain their own original path bases and must not be substituted blindly for the current map.

The ODG files retain editable native vector and text objects. Font and production checks are bounded checks of the supplied artwork, not a guarantee of identical output in every editor or operating system. Third-party font notices remain operative. Figure preparation used reproducible plotting and vector workflows; no image-generation model created scientific observations.
