S20.8 Records, integrity and reproduction

Supplementary Software 1 supplies the protocol locks, source hashes, compact producer and recipient trial tables for both campaigns, and separate coalescence controls. The retained per-trial measurements, required proof objects, protocols and source dependencies for the reported comparisons are supplied in Current_Reproducibility_Data.zip, with its file identity and replay instructions recorded alongside the software. This selected current reproducibility package is archived in Zenodo distribution 1.1.0 (https://doi.org/10.5281/zenodo.23649107) [2]. The compact analysis directories contain ANALYSIS.json, producer_trials.csv, recipient_trials.csv, producer_summary.csv, prefix_summary.csv, paired_trials.csv, paired_ratio_summary.csv and checker_summary.csv. Trial rows preserve all seven executions; the complete displayed V2/V3 tables retain all seven cases and all five recipient counts. The integration script records each compact input hash and checks trial completeness and inclusion status before generating the tables.

The benchmark README beside the frozen V3 runner supplies replay and report commands. A later local replay regenerated all 28 retained first-repetition final objects—seven cases, two producers and two protocols—byte-identically; every object passed separate checking, and V3 raw objects also matched. This reproduces functionality, not historical timing. Wall-clock values may change across runs or hosts. Historical three-run R13 measurements, development smoke tests and saved-proof coalescence remain separate collections. Main Figure 6 reports V3; S14–S15 and S18.3 retain the earlier implementation record. These campaigns establish no positive external UWB application.
